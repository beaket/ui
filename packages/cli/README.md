# @beaket/ui

CLI for adding Beaket UI components to your project.

**Documentation:** https://beaket.github.io/ui/

## Usage

```bash
npx @beaket/ui init
npx @beaket/ui add button
```

## Requirements

- React 18+
- Tailwind CSS

## Commands

| Command | Description |
|---------|-------------|
| `init` | Setup project configuration |
| `add <component>` | Add a component |
