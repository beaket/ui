# Contributing

## Setup

```bash
pnpm install
pnpm dev
```

## Adding a Component

1. Create `src/components/[name].tsx`
2. Create `src/components/[name].stories.tsx`
3. Add entry to `registry/registry.json`

## Commands

| Command | Description |
|---------|-------------|
| `pnpm dev` | Start Storybook |
| `pnpm build` | Build Storybook |
| `pnpm typecheck` | Run type check |
